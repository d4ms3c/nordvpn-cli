# Security policy

`nordvpn` drives the NordVPN app with your user's permissions, and `nordvpn mcp` lets AI agents do the same. Please report anything that could let a page, file, agent or other process change the VPN, read private data or run code without the user's consent.

Report vulnerabilities privately through **Security → Report a vulnerability** on GitHub, not in a public issue. Include the CLI version, macOS version and steps to reproduce, without real IP addresses, logs or account data.

Only the latest release is supported. Vulnerabilities in the NordVPN app itself belong to Nord Security, which runs a bug bounty program on HackerOne.
